# หา KOL คล้ายกัน (lookalike)

ใช้ Team API ตัวเดียวกับ skill `kol-search` (คีย์ส่วนตัวที่ `~/.nj_kol_key` — ถ้ายังไม่มี ดูขั้นตอนใน `kol-search/SKILL.md`)

```bash
KOL="${CLAUDE_PLUGIN_ROOT}/skills/kol-search/kol.sh"
bash "$KOL" lookalike @handle                                   # 20 คนที่คล้ายที่สุด
bash "$KOL" lookalike @handle '{"not_region":"กรุงเทพและปริมณฑล"}' 15   # คล้าย + เงื่อนไขเพิ่ม (ตัวกรองเหมือน kol-search)
bash "$KOL" lookalike @handle '{"tier":["Micro"],"grade":["A","B"]}'    # อยากได้ tier เล็กลง/เกรดดี
```

ผลแต่ละแถวมี `similarity` (0–100) และ `why` (เหตุผล เช่น "หมวดตรง 67% · วิว 1.1x · tier เดียวกัน · ภาคเดียวกัน") ตามด้วยข้อมูล KOL (`k`)

## วิธีคิดความคล้าย
- **หัวข้อ** (น้ำหนักมากสุด): hashtag ที่ใช้ซ้ำใน ~15 คลิปล่าสุด — แท็กเฉพาะ (#bydseal, #โสมนิศา) มีน้ำหนักมากกว่าแท็กกว้าง (#ป้ายยา); แท็กกว้างมาก ๆ (#fyp, #เทรนด์วันนี้) ไม่นับ
- หมวดเนื้อหาที่ซ้อนกัน · ยอดวิวกลางใกล้กัน · tier · ภาค · % ผู้ชมหญิง · อายุผู้ชมหลัก · ประเภทรถ (สายรถยนต์จะไม่ได้สายมอไซ และกลับกัน)
- **ค่าเริ่มต้นที่กรองให้อัตโนมัติ:** ตัดเกรด D (ใส่ `"grade"` เองถ้าอยากได้) · ผู้ชมไทย ≥ 60% (ใส่ `"min_th"` เองเพื่อเปลี่ยน)
- **ลำดับ** = ความคล้าย + คะแนนผลงาน (คนผลงานดีขึ้นก่อนเมื่อคล้ายพอ ๆ กัน)
- `why` บอก "หัวข้อตรง #…" ให้เห็นว่าทำเรื่องเดียวกันจริงไหม — ถ้าไม่มีหัวข้อตรง แปลว่าคล้ายแค่ระดับหมวด/ตัวเลข
— ไม่ได้ดูสไตล์คลิป/หน้าตา/โทนการพูด ให้ผู้ใช้เปิดดูโปรไฟล์ยืนยันก่อนเสนอลูกค้า

## ขั้นตอน
1. รับ handle ตัวอย่าง (ตัด @ และลิงก์ให้เหลือ handle) + เงื่อนไขเพิ่มถ้ามี (เช่น ต่างจังหวัด, tier เล็กกว่า, เคยทำแบรนด์)
2. ถ้าขึ้น `handle ... not in the vault` = คนนี้ยังไม่อยู่ในคลัง → บอกผู้ใช้ และเสนอให้ขอผู้ดูแลระบบเพิ่มเข้าคลัง หรือถามลักษณะ (หมวด/tier/ภาค) แล้วใช้ `kol-search` แทน
3. ขอเท่าที่ต้องการ (ค่าเริ่มต้น 20, สูงสุด 50) — กินโควตาเดียวกับ kol-search (1,500 ชื่อ/24 ชม./คีย์)
4. แสดงตาราง: ความคล้าย, เหตุผล, handle (ลิงก์), tier, วิวกลาง, ER, เกรด, จังหวัด, เคยทำกับแบรนด์
5. ถ้าผู้ใช้จะเอาไปเสนอลูกค้า แนะนำต่อด้วย skill `kol-shortlist-deck`

## กติกา
เหมือน `kol-search`: ไม่มีราคา (ถามราคา → ทีม KOL) · ห้ามวนหา lookalike ต่อกันเป็นทอดเพื่อเก็บรายชื่อเกินงาน · ห้ามส่งรายชื่อออกนอกบริษัท · ห้ามแชร์คีย์
