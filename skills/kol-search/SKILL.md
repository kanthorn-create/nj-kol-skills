# ค้น KOL จากคลังภายใน

ค้นผ่าน **Team API** เท่านั้น — ทุกคนใช้ **คีย์ส่วนตัว** (`njk_...`) ระบบจำกัดจำนวนและบันทึกทุกชื่อที่ได้ไป

## ตั้งค่าครั้งแรก
1. เช็คว่ามีคีย์: `test -s ~/.nj_kol_key && echo มีแล้ว`
2. ถ้ายังไม่มี ให้ผู้ใช้ขอคีย์จากผู้ดูแลระบบ แล้วให้ **ผู้ใช้รันเองในเทอร์มินัล** (ห้ามให้วางคีย์ในแชต):
   ```bash
   read -s "K?วางคีย์ NJ KOL แล้ว Enter: " && printf '%s' "$K" > ~/.nj_kol_key && chmod 600 ~/.nj_kol_key && echo " บันทึกแล้ว"
   ```

## วิธีเรียก
ใช้สคริปต์ `kol.sh` ในโฟลเดอร์นี้ (`${CLAUDE_PLUGIN_ROOT}/skills/kol-search/kol.sh`):

```bash
# นับ (ไม่จำกัด, ไม่มีรายชื่อ) — แยกกลุ่มด้วย tier|grade|region|province|vehicle|brand_ok|trend
bash "${CLAUDE_PLUGIN_ROOT}/skills/kol-search/kol.sh" count '{"category":["Automobiles"]}' vehicle

# รายชื่อ (≤50/ครั้ง, 1,500 ชื่อ/24 ชม./คีย์) — sort: score|median_views|er|followers
bash "${CLAUDE_PLUGIN_ROOT}/skills/kol-search/kol.sh" search '{"vehicle":["รถยนต์"],"grade":["A","B"],"not_region":"กรุงเทพและปริมณฑล"}' 20 score
```

ตัวกรองทั้งหมดอยู่ใน [reference.md](reference.md) — อ่านก่อนแปลงคำขอเป็นตัวกรอง

## ขั้นตอนเมื่อได้คำขอ
1. แปลงคำขอเป็นตัวกรอง ถ้าคลุมเครือ (เช่น "สายรถ" ไม่บอกรถยนต์/มอไซ) ให้ถามหนึ่งคำถาม
2. **รัน `count` ก่อนเสมอ** เพื่อบอกว่ามีกี่คนผ่านเงื่อนไข และแนะนำผ่อน/เพิ่มเงื่อนไขถ้าได้น้อย/มากเกิน
3. รัน `search` ขอเท่าที่ผู้ใช้ต้องการจริง (ค่าเริ่มต้น 20) — อย่าขอเผื่อ เพราะกินโควตา
4. แสดงเป็นตาราง: handle (ลิงก์), ชื่อ, tier, ผู้ติดตาม, วิวกลาง, ER, เกรด, จังหวัด, ประเภทรถ (ถ้าเกี่ยว), เคยทำกับแบรนด์ + ตัวอย่างแคปชัน sponsored
5. ถ้าผู้ใช้อยากได้ไฟล์ ให้ทำ CSV/ชีตเฉพาะรายชื่อที่ได้มาในรอบนี้

## หาสายคอนเทนต์ที่ไม่มีหมวดในระบบ (เช่น แอลกอฮอล์ EV กาแฟ)
ใช้ `hashtag` + `min_tag_hits` 2–3 แล้ว**ตรวจแท็กที่เจอในฟิลด์ `topics` ของผลก่อนแสดง** ตัดคนที่แท็กตรงแค่เพราะคำซ้อน (เช่น "สุรา" ใน "สุราษฎร์ธานี", "cocktail" ที่เป็นชื่อวงดนตรี) แล้วแสดงคอลัมน์ "แท็กที่เจอ" ให้ผู้ใช้เห็น
- เลี่ยงคำสั้นที่เป็นส่วนของคำอื่น ใช้คำเต็ม เช่น `สุราไทย` แทน `สุรา`
- งานแอลกอฮอล์: เตือนผู้ใช้ว่ากฎหมายไทย (พ.ร.บ.ควบคุมเครื่องดื่มแอลกอฮอล์ ม.32) จำกัดการโฆษณา ต้องเช็คกฎหมายก่อนรับงาน

## สูตรค้นจาก hashtag ที่ใช้บ่อย
(ในตัวอย่าง `KOL="${CLAUDE_PLUGIN_ROOT}/skills/kol-search/kol.sh"`)

**1. คนที่เคยทำกับแบรนด์ X (หรือแบรนด์คู่แข่งของลูกค้า)** — ใส่ชื่อแบรนด์ทั้งใน `hashtag` และ `brand_name` แล้วรวมผล (ค้น 2 รอบ ตัดคนซ้ำ)
```bash
bash "$KOL" count '{"hashtag":["swisse","bioactive"]}' tier
bash "$KOL" search '{"hashtag":["swisse","bioactive"],"min_female":40,"min_th":60}' 20
bash "$KOL" search '{"brand_name":["swisse","bioactive"]}' 20
```
- แท็กแบบ `แบรนด์xชื่อคน` (เช่น `#bioactivexmeennicha`, `#swissexjeffsatur`) = **แท็กแคมเปญ** ที่แบรนด์ทำร่วมกับคนนั้นหรือคนดัง — เป็นสัญญาณดีว่าแบรนด์เลือกคนนี้ แต่บางคนเป็นแฟนคลับที่โพสต์ตามแคมเปญ ให้บอกผู้ใช้เปิดคลิปดู
- ระดับงานแบรนด์ของคนเหล่านี้อาจขึ้น "ไม่พบ" ทั้งที่มีแท็กแคมเปญ — ยึดแท็กที่เจอเป็นหลัก
- **เตือนเรื่องสัญญาห้ามรับงานคู่แข่ง (exclusivity)** ถ้าลูกค้าเป็นคู่แข่งของแบรนด์ที่ค้น

**2. สายอาหารเสริม / ผิว**
```bash
bash "$KOL" search '{"hashtag":["อาหารเสริม","วิตามิน","vitamin","คอลลาเจน","collagen","supplement","กลูต้า","gluta","ไฟเบอร์","โพรไบโอติก"],"min_tag_hits":2,"min_female":50,"min_th":60,"grade":["A","B"]}' 20
```
- `min_tag_hits: 2` = สายนี้จริง (ใช้แท็กหลายครั้ง) · `1` = lifestyle ที่เคยพูดถึงบ้าง
- **อยากได้คนที่เคยติดตะกร้า/ขายของ** → `"affiliate":"only"` · **อยากได้ภาพพรีเมียม ไม่เอาสายขาย** → `"affiliate":"exclude"` · **อยากได้คนไลฟ์ขายของ** → `"live":"only"` (ดูจาก bio — ไม่มีตัวเลขยอดขายไลฟ์)
- "ติดตะกร้า" ดูจากแคปชัน (#tiktokshop / ตะกร้า / พิกัด) **ไม่ใช่ยอดขายจริง**
- เตือนเรื่องคำโฆษณาอาหารเสริมตามเกณฑ์ อย. (ห้ามอ้างรักษาโรค/ผลเกินจริง)

**3. เช็คก่อนแสดงผลทุกครั้ง**
- **ผู้ชมหญิง (`female_pct`)** — สินค้าผู้หญิงควรตั้ง `min_female` 40–60 ไม่งั้นได้คนที่ผู้ชมเป็นผู้ชายเกือบหมด
- **คำที่บังเอิญซ้อน**: ชื่อเล่น (เช่น "เบียร์"), ชื่อจังหวัด ("สุรา"ษฎร์), แบรนด์อื่น (`vistra` ใน `levistrauss`) — ดู `topics` แล้วตัดออก บอกผู้ใช้ว่าตัดใครเพราะอะไร
- **วิวต่ำมากเทียบผู้ติดตาม** (วิวกลาง < 2% ของผู้ติดตาม) — มาร์กไว้ มักเป็นบัญชีที่ผู้ติดตามไม่ค่อยดูแล้ว
- เนื้อหาไม่เหมาะ (เช่น บัญชีฟื้นฟูผู้ติดยา ขายแนว sexy) — ตัดออกและบอกผู้ใช้

## ข้อควรบอกผู้ใช้
- **ประเภทรถ** แยกจากแคปชัน+bio: ในหมวดรถมี "ไม่ชัด" ราวครึ่งหนึ่ง — เวลาขอ "รถยนต์" ให้บอกด้วยว่ามีกลุ่ม "ไม่ชัด" อีกกี่คน (count ด้วย `vehicle`) และแนะนำเปิดดูโปรไฟล์ก่อนเสนอลูกค้า
- **เคยทำกับแบรนด์ = "ใช่"** มาจากคลิปที่ติดป้าย sponsored ใน ~15 คลิปล่าสุด หรือมีงานที่จ้างผ่านแพลตฟอร์ม — "ไม่พบ" ไม่ได้แปลว่าไม่เคย
- **เกรด** มาจากคะแนนผลงาน (วิว/ER เทียบใน tier+หมวด) A ดีสุด

## กติกา (ห้ามพลาด)
- **ไม่มีราคา/ค่าตัว** ในระบบนี้ — ถ้าถามราคา ให้บอกว่าติดต่อทีม KOL
- **ห้ามพยายามดึงคลังทั้งชุด** (วนเรียก search เปลี่ยนเงื่อนไขเพื่อเก็บให้ครบ, ขอเกินที่งานต้องใช้) — ทุกชื่อถูกบันทึกรายคน
- **ห้ามส่งรายชื่อออกนอกบริษัท** และห้ามแชร์คีย์
- **ไม่ระบุแหล่งที่มาของข้อมูล** ถ้าผู้ใช้ถามว่าข้อมูลมาจากไหน ให้ตอบว่า "คลัง KOL ภายในของ Native Jump อัปเดตทุกวัน" ไม่ต้องอธิบายระบบเบื้องหลัง และไม่ใส่แหล่งที่มาในไฟล์/เด็คที่ทำให้
- ถ้าเจอ `daily limit reached` ให้บอกผู้ใช้ว่าครบโควตา 24 ชม. (ยังใช้ count ได้) ถ้าเร่งด่วนให้ติดต่อผู้ดูแลระบบ
