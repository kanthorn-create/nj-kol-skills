# KOL Shortlist Deck

เปลี่ยนรายชื่อ KOL ที่คัดแล้ว → เด็คเสนอลูกค้า (.pptx) ตาม CI ของ Native Jump

## อินพุตที่ต้องมี
- **รายชื่อ handle** (จาก `kol-search` / `kol-lookalike` / ที่ผู้ใช้พิมพ์มา) ไม่เกิน 50 คนต่อเด็ค
- **ชื่อลูกค้า/แคมเปญ** และ **โจทย์สั้น ๆ** (กลุ่มเป้าหมาย, เป้าหมายแคมเปญ) — ถ้าไม่มี ถามครั้งเดียว
- ออปชัน: จัดกลุ่มตาม tier / ภาค / บทบาท (hero–support–seeding), ภาษา (ไทยเป็นค่าเริ่มต้น)

## ขั้นตอน
1. ดึงข้อมูลล่าสุด (ชื่อที่ได้ไปแล้วใน 24 ชม. ไม่กินโควตาซ้ำ):
   ```bash
   bash "${CLAUDE_PLUGIN_ROOT}/skills/kol-search/kol.sh" profile @h1 @h2 @h3 > /tmp/shortlist.json
   ```
   handle ที่ไม่อยู่ในคลังจะหายไปจากผล — แจ้งผู้ใช้ว่าคนไหนไม่มีข้อมูล
2. สร้างเด็คด้วย skill **pptx** (มากับ Claude) ตามโครงด้านล่าง เซฟเป็น `KOL_Shortlist_<ลูกค้า>_<YYYY-MM-DD>.pptx` ในโฟลเดอร์ที่ผู้ใช้ทำงาน
3. ตรวจก่อนส่ง: ไม่มีราคา/ค่าตัว/คำว่า rate card · ตัวเลขตรงกับ JSON · ทุก handle มีลิงก์ TikTok · ข้อความภาษาไทยไม่ล้นกล่อง
4. บอกผู้ใช้ว่าข้อมูล ณ วันที่ (`updated_at`) และให้เปิดดูโปรไฟล์จริงก่อนส่งลูกค้า

## โครงเด็ค (16:9)
1. **ปก** — "KOL Shortlist" · ชื่อลูกค้า/แคมเปญ · วันที่ · โลโก้/ชื่อ Native Jump
2. **โจทย์ & วิธีคัด** — กลุ่มเป้าหมาย, เกณฑ์ที่ใช้คัด (หมวด, tier, ภาค, เกรด, เคยทำงานแบรนด์) แบบ bullet สั้น
3. **ภาพรวมรายชื่อ** — ตัวเลขใหญ่: จำนวน KOL · ผู้ติดตามรวม · ยอดวิวกลางรวม/คลิป · ER เฉลี่ย + ตารางสรุปแยก tier
4. **1 สไลด์ต่อ 2–3 KOL** (หรือ 1 คน/สไลด์ถ้า ≤ 8 คน) — ต่อคน: ชื่อ + @handle (ลิงก์), tier, ผู้ติดตาม, **ยอดวิวกลาง**, ER, หมวด, จังหวัด/ภาค, ผู้ชมหลัก (อายุ, % หญิง, % ไทย), "เคยร่วมงานกับแบรนด์" + ตัวอย่างแคปชัน sponsored 1 บรรทัด (ถ้ามี), จุดเด่น 1 ประโยคที่เขียนจากข้อมูล (ห้ามแต่งเกินข้อมูล)
5. **ตารางรวม** (ภาคผนวก) — ทุกคนในหน้าเดียว/หลายหน้า: handle, tier, ผู้ติดตาม, วิวกลาง, ER, จังหวัด
6. **ปิด** — ขั้นตอนถัดไป (ยืนยันรายชื่อ → เช็คคิว/ค่าตัวกับทีม KOL → brief)

## CI Native Jump (ใช้ตามนี้)
- สี: ink-900 `#14151A` (หัวข้อ/พื้นเข้ม) · grey-700 `#4D4F56` (เนื้อหา) · grey-500 `#737680` (คำอธิบาย) · grey-300 `#D3D4D9` (เส้น) · grey-200 `#E6E7EA` (การ์ด) · paper-50 `#F6F6F9` (พื้น) · **blue-600 `#1F4FD8` เป็นสีเน้นเดียว ใช้ไม่เกิน ~10% ของหน้า** · blue-100 `#E3EAFB` (พื้นเน้นอ่อน)
- ฟอนต์: **Prompt** (หัวข้อ) + **IBM Plex Sans Thai** (เนื้อหา); ตัวเลขเด่นใหญ่หนา
- หลัก: หนึ่งสีเน้นต่อหน้า · ห้ามส้ม/น้ำตาล · พื้นขาว-เทา เรียบ มีช่องว่าง

## ตัวเลข
ผู้ติดตาม/วิวแบบย่อ (12.3K, 1.2M) · ER ทศนิยม 1 ตำแหน่ง + % · "ยอดวิวกลาง" = median ของคลิปล่าสุด (ไม่ใช่ค่าเฉลี่ย) ให้เขียนหมายเหตุเล็กครั้งเดียวในสไลด์ภาพรวม

## กติกา
- **ห้ามใส่ราคา/ค่าตัว/งบ** แม้ผู้ใช้ขอ — บอกให้ขอตัวเลขจากทีม KOL แล้วใส่เอง
- ใช้เฉพาะรายชื่อที่ผู้ใช้คัดมา ห้ามดึงเพิ่มเพื่อทำเด็คใหญ่เกินโจทย์
- เด็คนี้ส่งลูกค้าได้ แต่ **ห้ามแนบไฟล์ JSON/ตารางดิบทั้งชุด** ไปกับเด็ค
